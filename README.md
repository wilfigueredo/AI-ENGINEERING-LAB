# AI Engineering Lab

Hands-on AI Engineering laboratory built with .NET.

This repository is dedicated to studying, implementing, and validating
Artificial Intelligence engineering concepts through practical experiments.

The goal is to move beyond theoretical knowledge by implementing each concept
in working .NET code.

## Topics

The laboratory currently covers or plans to cover:

- LLM integration
- Microsoft.Extensions.AI
- Conversation history
- Streaming responses with SSE
- Tools
- Function Calling
- Semantic Kernel
- Embeddings
- Vector similarity
- Vector Search
- Retrieval-Augmented Generation (RAG)
- Structured Outputs
- AI orchestration
- AI observability
- Retrieval evaluation
- Token usage and cost analysis

## Technology Stack

- .NET 9
- C#
- ASP.NET Core
- Microsoft.Extensions.AI
- Microsoft Semantic Kernel
- OpenAI
- xUnit
